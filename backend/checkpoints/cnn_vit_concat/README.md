# CNN-ViT Concat Baseline Checkpoint

Place the trained weights file for the CNN-ViT Concatenation Fusion baseline model here (e.g., `cnn_vit_concat_seed42.pth`).

### Note
- Do not commit large weight files (`.pt`, `.pth`, `.ckpt`) to Git.
- The path can be configured in `.env` or `configs/cnn_vit_concat_seed42_config.json`.
