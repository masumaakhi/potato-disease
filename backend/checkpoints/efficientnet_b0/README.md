# EfficientNet-B0 Checkpoint

Place the trained weights file for the baseline EfficientNet-B0 model here (e.g., `efficientnet_b0_seed42.pth`).

### Note
- Do not commit large weight files (`.pt`, `.pth`, `.ckpt`) to Git.
- The path can be configured in `.env` or `configs/cnn_efficientnet_b0_seed42_config.json`.
