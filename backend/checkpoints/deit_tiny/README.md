# DeiT-Tiny Checkpoint

Place the trained weights file for the baseline DeiT-Tiny (Data-efficient Image Transformer) model here (e.g., `deit_tiny_seed42.pth`).

### Note
- Do not commit large weight files (`.pt`, `.pth`, `.ckpt`) to Git.
- The path can be configured in `.env` or `configs/cnn_deit_tiny_seed42_config.json`.
