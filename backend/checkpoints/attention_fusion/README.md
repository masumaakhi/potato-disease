# Attention-Guided CNN-ViT Fusion Checkpoint

Place the trained weights file for the proposed Attention-Guided Lightweight CNN-ViT Fusion Network here (e.g., `attention_fusion_seed42.pth`).

### Note
- Do not commit large weight files (`.pt`, `.pth`, `.ckpt`) to Git.
- The path can be configured in `.env` or `configs/attention_cnn_vit_seed42_config.json`.
